# NIBIA Fabric Governance

NIBIA Fabric is an open-source project licensed under the Apache License 2.0. This document describes the lightweight governance model used for the current Experimental Alpha stage.

## Current maintenance model

NIBIA Fabric is currently maintained by its founding maintainer. The project is still early, so governance is intentionally simple rather than presenting a committee structure that does not yet exist.

Project development, issue discussion, pull requests, and release decisions should be handled publicly in the repository where practical, except for security reports and other information that should remain private.

## Contribution principles

Contributions are evaluated primarily on technical quality, security, compatibility, maintainability, and alignment with the project's documented scope.

Contributors use the Developer Certificate of Origin (DCO) sign-off described in [CONTRIBUTING.md](CONTRIBUTING.md). NIBIA Fabric does not currently require copyright assignment as a condition of contribution.

Code accepted into this repository is contributed under the repository's Apache-2.0 license unless a file or third-party component explicitly states different terms.

## Project and commercial boundaries

NIBIA Fabric is the open-source distributed compute core of NIBIA. The Apache-2.0 license applies to the software covered by that license; third-party projects retain their own licenses and notices.

The Apache-2.0 license does not itself grant rights to use NIBIA names or logos as trademarks or to imply official affiliation or endorsement.

## How governance may evolve

If the contributor and maintainer community grows, NIBIA Fabric governance may expand to include additional maintainers and broader technical stewardship.

A future neutral-foundation home may be considered if it becomes appropriate for the health and independence of the project. This document does not commit NIBIA Fabric to any particular foundation or future governance structure.

Governance changes should be documented publicly in this file and reviewed with the community as the project matures.
